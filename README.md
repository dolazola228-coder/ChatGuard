# Chat Rule Watcher — серверный мод

Мод для Fabric 1.21.11. Проверяет сообщения на стороне сервера: игрокам не нужно устанавливать мод на клиент, а проверка работает для всего сервера.

## Кому приходят оповещения

- По умолчанию — всем онлайн-операторам Minecraft с уровнем прав 2 или выше.
- Дополнительно можно указать UUID или ники хелперов в конфигурации `config/chatrulewatcher.json`.
- Сообщение приходит автоматически в игровой чат; команды для получения оповещений не нужны.

Пример конфигурации:

```json
{
  "notifyOperators": true,
  "helperUuids": [],
  "helperNames": ["HelperNick", "AnotherHelper"]
}
```

UUID предпочтительнее ника: ник может измениться. После изменения списка перезапустите сервер.

## Проверяемые правила

- 3.1 — распространённые оскорбления из встроенного списка.
- 3.2 — более 70% заглавных букв (не менее 8 букв).
- 3.3 — упоминание родственников.
- 3.4 — повтор одинаковых сообщений или высокая частота сообщений.
- 3.5 — ссылки, приглашения Discord/Telegram, домены и IP-адреса с портом.
- 3.6 — некоторые фразы с оскорбительной критикой сервера/администрации.
- 3.7 — некоторые фразы выдачи себя за администрацию.
- 3.8 — отдельные политические/конфликтные ключевые слова.
- 3.9 — призывы нарушать правила.
- 3.10 — некоторые фразы попрошайничества.

Это эвристический фильтр по ключевым словам, а не ИИ: возможны ложные срабатывания и пропуски. Списки фраз можно расширить в `ChatRuleWatcher.java`.

## Сборка

Требуются Java 21 и Gradle. В каталоге проекта выполните:

```sh
gradle build
```

Готовый файл появится в `build/libs/ChatRuleWatcher-1.0.0.jar`. Установите его в папку `mods` **сервера** вместе с Fabric API и Fabric Loader. Клиентам устанавливать этот мод не требуется.
